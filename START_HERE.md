## 🔧 Troubleshooting

**Search not working?**
- Make sure you pressed `/` first to focus the search box
- Try clearing the search box to reset results

**Data not updating?**
- Press `R` to manually refresh
- Auto-updates every 8 seconds automatically

**Theme looks strange?**
- Toggle with `T` to switch back
- Refresh page to reload saved theme

**Lost your watchlist?**
- Export before clicking "Reset" in settings!
- Settings → Reset clears all data

**Keyboard shortcuts not working?**
- Make sure you're not in a text input field
- Press `?` to verify the correct shortcut keys
